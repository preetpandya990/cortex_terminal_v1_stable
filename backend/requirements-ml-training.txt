# The core ML/AI stack — tensorflow[and-cuda], torch, keras (via TF), onnx,
# onnxruntime-gpu, xgboost, optuna, scikit-learn, transformers, optimum,

# Rationale: this file previously re-pinned tensorflow==2.15.0 / keras==2.15.0 /

# what caused the cascading GPU-training breakage (TF/Keras 2-vs-3 + numpy ABI):
# a `pip install -r requirements-ml-training.txt` would silently downgrade
# TensorFlow 2.21→2.15 and force Keras 2. Never re-pin the core stack here.
#
# This file holds ONLY training/evaluation-time extras not already governed by
# requirements.txt, pinned to the verified-good environment (2026-05-18).
#
# Note: Combinatorial Purged CV, Deflated Sharpe, PBO and the cost-aware
# backtest are implemented in-house (app/ml/evaluation/) — NOT via skfolio or
# mlfinlab — to avoid a numpy 1.x→2.x dependency cascade and paid-tier licences.
# See ML_IMPLEMENTATION_PLAN.md §3 for the rationale.
